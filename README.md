# Kyle Koehn personal tools website

Public information only, hosted at https://kylekoehn.com/ using GitHub Pages from main, repository root.

- index.html: neutral homepage describing Sophia and Kyle Media.
- privacy.html: the single shared privacy policy, with separate app access descriptions.
- terms.html: shared personal-use terms.
- CNAME: kylekoehn.com; retain this when editing the website.

Edit these files and push main. Check all three public pages over HTTPS after deployment. Keep the privacy-policy date current when its substance changes.

Both Google OAuth apps point to these same three URLs. Changes to Google app names, links or branding may require Google's separate branding check. This website does not combine their clients, scopes, grants, credentials or Google projects.

The old sophia.kylekoehn.com repository contains compatibility redirects here; maintain the actual policy only in this repository.

Never add credentials, media, private manuscripts or account data to this public repository.
