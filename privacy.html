Privacy Policy

Last updated: October 19, 2026

This policy covers Kyle Koehn's personal tools, including Sophia and Kyle Media. These tools are used by their owner and are not offered as public services.

What each app accesses

Sophia

With the owner's permission, Sophia accesses the owner's Google Gmail and Calendar data to help read and organize messages, plan travel, and manage schedules. Access depends on the permissions the owner grants to Sophia.

Kyle Media

With the owner's permission, Kyle Media uses limited Google Drive access to read and manage files created or opened through the app. It stores and restores selected media, verification records, and resumable job data in a separate private media workspace. The canonical hymn archive is outside that writable workspace.

Its separate YouTube connection accesses the owner's channel, videos, and playlists to upload finished media and organize playlists. It can remove superseded videos when the owner selects that revision policy. Uploads are private by default; public publication requires the owner's explicit authorization.

Each app has separate Google authorization and credentials. Sharing this policy does not grant one app the other app's permissions.

How data is used and stored

Google user data is used only for the owner's requested features. The tools do not sell that data, use it for advertising, or use it to train generalized AI models.

Processing can take place on the owner's computer or through private cloud environments and service providers selected by the owner. For example, selected scripts or audio can be sent to narration or transcription services to perform the requested task. Providers process data under their own terms and settings, which vary by service and tier.

Private messages remain in the owner's accounts or selected working environment. Selected media and recovery records are kept in private Drive folders, the owner's YouTube library, or local/cloud working directories. Source code and compact project records are kept in private GitHub repositories.

API keys and OAuth tokens are kept outside source repositories and media snapshots, in protected local settings or the chosen cloud environment's secret settings. This public website contains app information, not private project data or credentials.

These apps' use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube API Services

Kyle Media uses YouTube API Services. Google handles data under its Google Privacy Policy.

Retention and removing access

The owner controls retention of saved project data and media. Previous versions may be retained for recovery; configured media revision cleanup can remove superseded videos. Service providers apply their own retention rules.

The owner can revoke each app's Google access at myaccount.google.com/permissions and remove its saved credentials from local or cloud settings. Revoking access stops future authorized requests; it does not by itself delete previously saved files, messages, or videos.
